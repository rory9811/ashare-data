# ashare-data

每周自动计算的 A 股和美股行情表，供《A股主题账本》《美股主题账本》每周体检读取价格。
所有数字都由程序从复权日线算出，账本只引用，不手算。（仓库名沿用最初的 A 股版本，现在两个市场都在这里。）

代码在 `main` 分支；数据每个市场一个分支，只保留最新一份（每次运行用一个没有历史的新提交覆盖），所以仓库不会每周变大：

| 市场 | 数据分支和文件 | 数据源 | 证券范围 | 基准 | 运行时间（北京时间） |
| --- | --- | --- | --- | --- | --- |
| A 股 | `data-cn` 分支：`cn/ma_latest.csv`、`cn/history_w.csv`、`cn/ohlcv/<代码>.csv`、`cn/meta.json` | baostock，前复权日线 | 全部 A 股、ETF、指数 | 沪深 300（000300.SH） | 周五 18:23，周六 03:17 补跑 |
| 美股 | `data-us` 分支：`us/ma_latest.csv`、`us/history_w.csv`、`us/ohlcv/<代码>.csv`、`us/meta.json` | Yahoo Finance（yfinance），复权日线 | 全部在美上市股票（含 ADR）和 ETF，加主要指数、VIX、10 年期美债收益率、原油、天然气、黄金、白银、铜期货、美元指数 | SPY | 周六 06:13，09:43 补跑 |

美股批量下载偶尔漏掉个别代码的最后几根日线（例如拆股当天），程序会逐个重取一次；仍然停在最新交易日之前的代码和日期写在 `meta.json` 的 `stale` 里，账本引用这些代码时要注明数据日期并另行核对。

GitHub 的定时任务常常排队晚几个小时，所以每个市场排两次。第二次发现数据已经覆盖最新交易日就直接跳过；A 股当天日线还没入库时也跳过，留给下一次。手动运行（Actions 页面 Run workflow）或改了代码触发的运行总是重新计算。

## `ma_latest.csv` 的列（两个市场相同）

| 列 | 含义 |
| --- | --- |
| code | 代码。A 股如 600519.SH；美股用 Yahoo 写法，如 MU、BRK-B、^GSPC、BZ=F |
| name、kind | 名称；股票、ETF、指数、利率、商品或汇率 |
| date | 最后一个有数据的交易日 |
| close | 复权收盘价 |
| ma50、ma200 | 50 日、200 日均线 |
| trend | 方向：上涨、上涨中回调、转跌、下跌、下跌中反弹、转涨、数据不足 |
| chg_1w、chg_4w、chg_13w | 近 1、4、13 周（5、20、60 个交易日）涨跌幅，% |
| rel_1w、rel_4w、rel_13w | 相对基准：同期涨跌幅减去基准的涨跌幅，百分点 |
| high_250、pct_from_high | 近 250 个交易日最高收盘价，收盘价距它的百分比 |
| amt_20d、amt_pct | 近 20 个交易日的日均成交额（当地货币）；它在本市场全部股票里的分位，0–100，越大越活跃（只给股票算）。账本用它给代表股设门槛（门槛写在账本规则里）：成交稀少的股票价格噪音大、数据最容易缺失；用分位不用固定金额，是为了不随市场冷热失效 |

方向规则：50 日均线在 200 日均线之上时，收盘价在 50 日均线之上记“上涨”，在 50 日和 200 日均线之间记“上涨中回调”，跌破 200 日均线记“转跌”；50 日均线在 200 日均线之下时，收盘价在 50 日均线之下记“下跌”，在两条均线之间记“下跌中反弹”，站上 200 日均线记“转涨”；不足 200 个交易日记“数据不足”。收盘价在 200 日均线之上的三种（上涨、上涨中回调、转涨）归“上涨一边”，其余三种归“下跌一边”。

美股的 ^TNX 是 10 年期美债收益率乘以 10（例如 43.5 表示 4.35%）。

## 两年周线（画图、读价格结构用）

都和 `ma_latest.csv` 出自同一次取数，所以图和数字对得上。周的标签是那一周的周五日期，值取那一周的交易日。

- `history_w.csv`：每行一个代码，第一列是代码，后面 104 列各是一周的复权收盘价；那周没有数据（尚未上市、停牌）就留空。一次比较很多代码时用。
- `ohlcv/<代码>.csv`：每个代码一个文件，每周一行，列为 `week, open, high, low, close, amount`：那一周的开盘（第一个交易日）、最高、最低、收盘（最后一个交易日），都已复权；`amount` 是那一周的成交额（A 股取交易所公布的成交金额；美股是每日收盘价 × 成交量之和，近似值），单位是当地货币。用成交额不用成交量，因为拆股、送转会改变股数，但不改变成交额。期货的“成交额”是价格乘以合约张数，不是真实金额，只用来和它自己的过去比；指数在 Yahoo 上多半没有成交量，成交额记 0。文件名里字母、数字、点、横线以外的字符换成下划线：`^GSPC` → `_GSPC.csv`，`BZ=F` → `BZ_F.csv`。

## 读取（不用登录）

只取需要的行，行首匹配加逗号，避免误匹配：

```
curl -sL https://raw.githubusercontent.com/rory9811/ashare-data/data-cn/cn/ma_latest.csv | grep -E "^code,|^(000300\.SH|600519\.SH),"
curl -sL https://raw.githubusercontent.com/rory9811/ashare-data/data-us/us/ma_latest.csv | grep -E "^code,|^(SPY|MU|\^GSPC),"
```

画一个主题的图并算出价格结构（只要下载脚本；它会把需要的周线文件自动下载到 `ohlcv/`；只用到 matplotlib 和 curl）：

```
mkdir -p /tmp/chart && cd /tmp/chart
curl -sL https://raw.githubusercontent.com/rory9811/ashare-data/main/scripts/theme_chart.py -o theme_chart.py
python3 -I theme_chart.py --market us --codes MU,WDC,STX --out storage > storage.json
```

得到三样东西：

- `storage.png`，给模型看。每只代表股一格：周 K 线（对数刻度，美股绿涨红跌、A 股红涨绿跌）、10 周和 40 周均线（约等于 50 日和 200 日均线）、程序找出的波段高低点（小三角）、最近的横盘区间（浅色方框），下面是每周成交额和它的 10 周均值；最下面两格是各代码和基准的走势对比（起点记为 100）和相对基准的强弱。
- `storage.widget.txt`，账本文档里图表组件的代码（走势对比）。
- 标准输出（上例存进 `storage.json`）：
  - 数字摘要：区间涨跌、两年内高低点和日期、距高点回撤、相对基准、近 13 和 26 周涨跌。
  - 价格结构（每个代表股和基准）：波段阈值（周波动率的 3 倍，限制在 6% 到 35%，回落或反弹超过它才算新波段）、最近的波段高低点、道氏结构（高低点抬高还是降低）、当前这一段、中期回撤和主要趋势回撤、道氏反转信号、最近两段上涨和下跌的幅度与成交额、横盘区间与突破状态（区间用收盘价定上下沿，盘中冲出又收回算被拒绝的试探）、温斯坦阶段（40 周均线）、趋势模板（米勒维尼八条的周线版）、52 周位置、相对强弱线、量价（近 13 周上涨周与下跌周成交额之比、近 26 周放量大幅波动的周、近 6 周逐周的涨跌、振幅、成交额倍数和收盘位置）。
  - 趋势体质：两年涨跌幅、加速度、波动变化、上涨周占比，和主题是否达到急涨门槛（两年涨幅 ≥100% 且超出基准 ≥100 个百分点，取自 Greenwood、Shleifer、You 2019；只对上涨成立，向下的主题只看前几项）。

每项读数对应哪种理论、怎么解读，见《股票价格理论手册》。图只用来看形状，数字以标准输出和 `ma_latest.csv` 为准。

从价格倒推主题时，先做一次趋势扫描（只下载 `ma_latest.csv`，不读周线）：

```
curl -sL https://raw.githubusercontent.com/rory9811/ashare-data/main/scripts/trend_scan.py -o trend_scan.py
python3 -I trend_scan.py --market us --top 25
```

它按近 13 周相对大盘的强弱，列出三组资产：大类资产和主要指数（全部）；成交额排在本市场前 5% 的股票（`amt_pct` ≥ 95，A 股去掉 ST），最强和最弱各 25 只；日均成交额排在本市场 ETF 前 10% 的 ETF（去掉杠杆、反向和期权收益类），最强和最弱各 25 只。同一类资产一起出现在某一头，说明可能有一股力量在推；是不是主题、驱动是什么，按账本规则另行判断。

## 代码

- `scripts/common.py`：两个市场共用的计算和输出
- `scripts/update_cn.py`、`scripts/update_us.py`：各市场取数（A 股六千多个代码要逐个查询，工作流先判断要不要算，再分六份并行取数，最后合并发布；缺任何一份都不发布）
- `scripts/theme_chart.py`：按代码画主题的周 K 线图、走势对比，并算出价格结构
- `scripts/trend_scan.py`：趋势扫描，列出大类资产、最大的股票和最活跃的 ETF 里相对强弱排在两头的
- `.github/workflows/cn-weekly.yml`、`us-weekly.yml`：定时运行，把结果覆盖到各自的数据分支
